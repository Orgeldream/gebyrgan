GEBYRGAN - A beat mulcher for BRECAN Mk2 but it’s also its own thing.

Feed it audio and get weird blippy breaks compatible with BRECAN mk2.

If you want to make your own files to use with BRECAN Mk2 the parameters are:

Target RMS: −15.3 dBFS
Target peak: −1.5 dBFS
Output length: 470400 samples
Format: 16-bit · 44.1k · MONO WAV

You need 16 of them named Break1.wav to Break16.wav
